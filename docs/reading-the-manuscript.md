# Reading the manuscript

The paper lives in one file:

`Prediction_as_Power_Rishabh_Aryan_Manuscript.ipynb`

It is a Jupyter notebook of Markdown cells only. There is no laboratory code in that file. GitHub renders the cells on the file page.

## On GitHub

Open the notebook URL and wait for MathJax to typeset equations. If an old version appears, hard-refresh the browser.

Equations use standard dollar delimiters:

- inline: `$R_t$`
- display: `$$ ... $$`

## Locally

```bash
git clone https://github.com/Rishabh-bgp/prediction-as-power.git
cd prediction-as-power
```

Open the `.ipynb` in JupyterLab, VS Code, or any notebook viewer. No Python packages are required to *read* the manuscript notebook.

## Structure

1. Title and author block
2. Abstract and keywords
3. Sections I–X
4. Tables
5. References
6. Appendices
