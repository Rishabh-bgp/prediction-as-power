# Contributing

This repository is the open working paper *Prediction as Power*.

## What belongs here

- Corrections to citations, institutional descriptions of SDAC, SIDC and balancing, or typographical errors in the manuscript notebook.
- Suggested wording that keeps laboratory magnitudes labelled as laboratory magnitudes.
- Documentation improvements.

## What does not belong here

- Confidential commercial forecast products.
- Personal data.
- Claims that the synthetic laboratory numbers are official ENTSO-E or German market statistics.

## How to propose a change

1. Open an issue describing the section and the proposed correction.
2. Fork the repository and edit `Prediction_as_Power_Rishabh_Aryan_Manuscript.ipynb` or the files under `docs/`.
3. Open a pull request against `main`.

The manuscript notebook is Markdown only. Do not add executable laboratory code to that file unless the author asks for a separate notebook.
